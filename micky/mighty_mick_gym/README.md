## Mighty Mick's Gym

This is a hacked up version of the Nordic Edge AI Neuton gesture recognition application, re-purposed to be a boxing trainer.

The model in  nrf_edgeai_generated/ is the last I used, trained with.

The only MCU I used it with, and for which this code/config is known to work, are the nRF54L15 Tags, so the config in configuration/nrf54l15tag_nrf54l15_cpuapp (basic prj.conf, no release or anything fancy).
